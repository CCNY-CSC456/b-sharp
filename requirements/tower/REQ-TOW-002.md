# REQ-TOW-002: Message Sending Utility

The system shall let the radar, tower, and command subsystems send messages to one another.

- A message has a sender, a recipient, and content.
- A subsystem shall be able to send a message to any other subsystem.
- A subsystem shall be able to retrieve all messages addressed to it.
